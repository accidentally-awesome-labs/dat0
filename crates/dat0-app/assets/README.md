# dat0-app/assets — bundled fixtures

Read-only static fixtures embedded into the dat0 binary via `include_bytes!`
or referenced at runtime. Updates to this directory bump binary size; see
P3b spec §11 (binary growth target ~1 MB total) before adding new files.

License attribution for third-party assets is recorded here. The top-level
`NOTICE.md` is regenerated by `cargo-about` during release (P3b T13) and
will not include these entries automatically — keep the entries here
authoritative until the cargo-about run picks them up.

## sparkle-public-key.txt

In-house. No third-party license — generated as part of the macOS
Sparkle auto-updater wiring (P1).

## iris.csv

- **Source URL:** <https://raw.githubusercontent.com/scikit-learn/scikit-learn/main/sklearn/datasets/data/iris.csv>
- **Origin:** scikit-learn fork of Fisher's Iris dataset
- **License:** BSD-3-Clause (scikit-learn upstream)
- **Why:** Empty-state sample (T7) and offline CI fixture. Always
  available even when the user has no network access.

## chinook.sqlite

- **Source URL:** <https://github.com/lerocha/chinook-database/raw/master/ChinookDatabase/DataSources/Chinook_Sqlite.sqlite>
- **Origin:** lerocha/chinook-database

- **Why:** Empty-state sample (T7) — the canonical SQLite-ATTACH

## NYC taxi (NOT bundled — remote)

The third sample (`nyc_taxi.parquet`) is **not** in this directory.
It's hosted as a GitHub Release asset and fetched on-demand by
`sample_data::ensure_remote_extracted` (T8 lands the fetch + SHA-256
verify). The URL + checksum are constants in `src/sample_data.rs`.

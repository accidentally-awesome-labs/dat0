# Support

## Bugs and feature requests

Use [GitHub Issues](https://github.com/accidentally-awesome-labs/dat0/issues) for reproducible bugs and feature requests. Include your version or commit, OS/version/architecture, minimal reproduction steps, and expected versus actual behavior. Prefer a small synthetic dataset; never upload private datasets, credentials, or unsanitized logs.

## Questions

Use [GitHub Discussions](https://github.com/accidentally-awesome-labs/dat0/discussions) for usage and architecture questions. The [documentation index](docs/README.md) and [contribution guide](CONTRIBUTING.md) are useful starting points.

Documentation fixes can go directly to a pull request, or to an issue labeled `documentation`.

## Private reports

- **Security vulnerabilities or suspected data leaks:** use [GitHub private vulnerability reporting](https://github.com/accidentally-awesome-labs/dat0/security/advisories/new) or email **security@dat0.app**. Follow [SECURITY.md](SECURITY.md); do not post sensitive details in public issues or discussions.
- **Conduct concerns:** email **conduct@dat0.app**. See the [Code of Conduct](CODE_OF_CONDUCT.md).

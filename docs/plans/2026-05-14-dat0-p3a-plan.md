# dat0 P3a — Scratch + DataGrid hot path — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Match the P1 + P2 cadence: full two-stage review on T0 spike + tasks that touch >3 files or have API-contact risk; combined-verify (single review pass) on verbatim-mechanical tasks. Plan-defects go to `docs/deferrals.md` as new `PD-NNN` entries — do not fix in place unless they block the task.

**Goal:** Land the engine-to-pixel hot path for Scratch mode — drop a file in a GPUI window, see it render in a virtualized DataGrid sustaining 60 fps over 1 million rows — plus the cross-cutting infrastructure (single-instance, multi-window registry, sandbox lifecycle) and deferral closures (D-011, D-012) the spec lists under P3a.

**Spec:** `docs/specs/2026-05-14-dat0-p3a-scratch-datagrid-design.md` (committed 2026-05-14, `9b65d5d`). Read it before T0.

**Architecture:** Single-process / single-instance app. PID + flock guards the singleton; a Unix domain socket forwards subsequent `dat0` launches into the running process. Inside the process: an in-process `WindowRegistry` holds live windows + scaffolds a `WorkspaceMutex` API consumed in P4. Each window owns one `Session` (scratch dir + DuckDB engine + tab list). The DataGrid wraps `gpui-component`'s `Table` and consumes `duckdb::arrow::RecordBatch` directly (no standalone `arrow = ` dep — CI grep gate enforces).

**Tech Stack:** Rust 2024, GPUI `=0.2.2`, gpui-component v0.5.1 (pinned commit `0f0ab35...`), `duckdb-rs =1.4.4` (features `bundled,json,parquet`), Apache Arrow via `duckdb::arrow` re-exports, tokio (multi-thread + macros + fs + sync + **+net** added here), `fs4` (advisory file lock), `interprocess` or `tokio::net::UnixListener` (UDS), `uuid` (v7), `lru`, `criterion` for the bench. macOS + Linux v1.

  ```rust
  //! Second `dat0` launch detects the lock, connects to the UDS, sends

  //! new Window on the main thread.

  //!   $STATE/dat0.pid   — text PID + flock guard
  //!   $STATE/dat0.sock  — Unix domain socket (JSON-lines protocol)

  use serde::{Deserialize, Serialize};
  use std::fs::{File, OpenOptions};
  use std::io::Write;
  use std::path::{Path, PathBuf};
  ```

  ```rust
  pub fn try_acquire(state_dir: &Path) -> Result<Option<Self>> {
      use fs4::FileExt;
      std::fs::create_dir_all(state_dir)
          .with_context(|| format!("create state dir {}", state_dir.display()))?;
      let pid_path = state_dir.join("dat0.pid");
      let sock_path = state_dir.join("dat0.sock");

      let mut pid_file = OpenOptions::new()
          .create(true)
          .read(true)
          .write(true)
          .truncate(false)
          .open(&pid_path)
          .with_context(|| format!("open pid file {}", pid_path.display()))?;

      // Non-blocking flock. Held flock = another live instance.
      // Stale PID file with no holder = flock succeeds.
      match pid_file.try_lock_exclusive() {
          Ok(()) => {
              // We're the singleton. Rewrite PID + return.
              pid_file.set_len(0).context("truncate pid file")?;
              write!(pid_file, "{}", std::process::id())
                  .context("write pid")?;
              pid_file.sync_all().context("fsync pid file")?;
              Ok(Some(Self { pid_file, pid_path, sock_path }))
          }
          Err(_) => Ok(None), // contention
      }
  }
  ```

  ```rust
      use interprocess::local_socket::traits::Stream;
      use interprocess::local_socket::{GenericFilePath, Name, ToFsName};

      std::io::Write::write_all(&mut stream, line.as_bytes())
  ```

  ```rust
  impl AppLock {
      /// Block-and-serve UDS messages. Each line is one `OpenWindowMessage`.
      /// Calls `handler` for every received message. Runs on a dedicated
      /// tokio task (caller spawns it).
      pub async fn serve(
          &self,
          handler: impl Fn(OpenWindowMessage) + Send + Sync + 'static,
      ) -> Result<()> {
          use interprocess::local_socket::tokio::prelude::*;
          use interprocess::local_socket::{GenericFilePath, ToFsName};
          use std::sync::Arc;
          use tokio::io::{AsyncBufReadExt, BufReader};

          // Stale socket file from a previous (crashed) instance.
          let _ = std::fs::remove_file(&self.sock_path);
          let name = self
              .sock_path
              .as_path()
              .to_fs_name::<GenericFilePath>()
              .context("build UDS name")?;
          let listener = interprocess::local_socket::ListenerOptions::new()
              .name(name)
              .create_tokio()
              .context("bind UDS")?;
          let handler = Arc::new(handler);

          loop {
              let stream = match listener.accept().await {
                  Ok(s) => s,
                  Err(e) => {
                      tracing::warn!("UDS accept failed: {}", e);
                      continue;
                  }
              };
              let h = Arc::clone(&handler);
              tokio::spawn(async move {
                  let mut lines = BufReader::new(stream).lines();
                  while let Ok(Some(line)) = lines.next_line().await {
                      match serde_json::from_str::<OpenWindowMessage>(&line) {
                          Ok(msg) => h(msg),
                          Err(e) => tracing::warn!("UDS bad message: {}", e),
                      }
                  }
              });
          }
      }
  }
  ```

  ```rust
  //!
  //! The registry tracks `WindowHandle`s so the AppLock UDS callback knows
  //! how many windows are open (used by Cmd-N spawn, last-window-closes
  //! shutdown, and orphan-recovery banner dispatch). The WorkspaceMutex
  //! map is scaffolded here per P2 retro #1 but not exercised until P4
  //! SQL Console / Workspace mode lands.

  use std::collections::HashMap;
  use std::path::PathBuf;
  use std::sync::Arc;
  use tokio::sync::Mutex;
  use uuid::Uuid;

  #[derive(Debug, Clone)]
  pub struct WindowHandle {
      pub window_id: Uuid,
  }

  pub struct WindowRegistry {
      windows: Vec<WindowHandle>,
      workspace_mutex: HashMap<PathBuf, Arc<Mutex<()>>>,

      }

      }

      pub fn live_windows(&self) -> impl Iterator<Item = &WindowHandle> {

      /// the same `Arc<Mutex<()>>`; concurrent workspace opens serialize on it.
      /// P3a does not call this; tests prove correctness in advance.
      pub fn workspace_mutex(&mut self, canonical_path: &std::path::Path) -> Arc<Mutex<()>> {
          self.workspace_mutex

      }
  ```

  ```rust
          let scratch_dir = state_root.join("scratch").join(window_id.to_string());

      /// Recover a previously-orphaned session dir.
      pub async fn recover(scratch_dir: PathBuf, engine_budget_bytes: u64) -> Result<Self> {
          let window_id = scratch_dir
              .file_name()
              .and_then(|s| s.to_str())
              .and_then(|s| Uuid::parse_str(s).ok())
              .context("scratch dir name must be a UUID")?;
          let state_path = scratch_dir.join("session.json");
          let state: SessionState = if state_path.exists() {
              let bytes = std::fs::read(&state_path).context("read session.json")?;
              serde_json::from_slice(&bytes).context("parse session.json")?
          } else {
              SessionState::default()
          };
          let engine = build_engine(&scratch_dir, engine_budget_bytes).await?;
          Ok(Self {
              window_id,
              scratch_dir,
              engine: Arc::new(engine),
              tabs: state.tabs,
              active_tab: state.active_tab,
          })
      }

      pub fn tabs(&self) -> &[Tab] { &self.tabs }
      pub fn active_tab(&self) -> Option<&Tab> {
          self.active_tab.and_then(|i| self.tabs.get(i))
      }

      pub fn add_tab(&mut self, tab: Tab) -> Result<()> {
          self.tabs.push(tab);
          self.active_tab = Some(self.tabs.len() - 1);
          self.persist()
      }

      pub fn set_active(&mut self, index: usize) -> Result<()> {
          if index >= self.tabs.len() {
              anyhow::bail!("tab index out of range: {}", index);
          }
          self.active_tab = Some(index);
          self.persist()
      }

      fn persist(&self) -> Result<()> {
          let state = SessionState {
              tabs: self.tabs.clone(),
              active_tab: self.active_tab,
          };
          let bytes = serde_json::to_vec_pretty(&state).context("serialize session.json")?;
          let path = self.scratch_dir.join("session.json");
          let tmp = path.with_extension("json.tmp");
          std::fs::write(&tmp, &bytes).with_context(|| format!("write {}", tmp.display()))?;
          std::fs::rename(&tmp, &path).context("atomic rename session.json")?;
          Ok(())
      }
  ```

  ```rust
  //! GPUI file-drop handler: detect format → register_file → tab append.
  //!
  //! Unsupported extension (and `.sqlite`) → Banner + drop. Engine error
  //! → Banner with err message + drop. Success → Tab + active.

  use anyhow::{Context, Result};
  use dat0_engine::{FileFormat, RegisterOpts};
  use crate::error_ux::Banner;
  use crate::session::{Session, Tab};
  use parking_lot::Mutex;
  use std::path::PathBuf;
  use std::sync::Arc;

  pub async fn handle_drop(
      paths: Vec<PathBuf>,
      session: Arc<Mutex<Session>>,
  ) -> Vec<DropOutcome> {
      let mut out = Vec::with_capacity(paths.len());
      for path in paths {
          out.push(handle_one(path, &session).await);
      }
      out
  }

  #[derive(Debug)]
  pub enum DropOutcome {
      Registered { table_name: String, source_path: PathBuf },
      Unsupported { path: PathBuf, extension: Option<String> },
      EngineError { path: PathBuf, error: String },
  }

  async fn handle_one(path: PathBuf, session: &Mutex<Session>) -> DropOutcome {
      let fmt = match FileFormat::from_extension(&path) {
          Some(f) => f,
          None => {
              let ext = path
                  .extension()
                  .and_then(|s| s.to_str())
                  .map(|s| s.to_string());
              let label = ext.clone().unwrap_or_else(|| "(no extension)".to_string());
              Banner::push_warning_message(format!("Unsupported file type: {}", label));
              return DropOutcome::Unsupported { path, extension: ext };
          }
      };
      let engine = session.lock().engine.clone();
      let opts = RegisterOpts { format: Some(fmt), ..Default::default() };
      match engine.register_file(&path, opts).await {
          Ok(info) => {
              let mut s = session.lock();
              s.add_tab(Tab {
                  table_name: info.name.clone(),
                  source_path: Some(path.clone()),
              })
              .expect("persist tab state");
              DropOutcome::Registered {
                  table_name: info.name,
                  source_path: path,
              }
          }
          Err(e) => {
              let msg = format!("{}: {}", path.display(), e);
              Banner::push_warning_message(msg.clone());
              DropOutcome::EngineError { path, error: msg }
          }
      }
  }
  ```

  ```rust
  //! 1M-row virtualized-scroll bench.
  //!
  //! Generates a synthetic Arrow batch (int + float + string + bigint
  //! + nullable), drives the same `render_cell` dispatch the live grid
  //! uses over the full row range, samples frame time. The bench is GPU
  //! kernel-independent — it measures the cost of the per-cell render
  //! decision + Arrow column access path that dominates real-world
  //! scroll frames once the widget reaches steady state. Real GPU
  //! frame-pacing is verified at P10 on the provisioned self-hosted GPU
  //! runner; P3a's metric is an *engine + cell-render* upper bound.

  use criterion::{black_box, criterion_group, criterion_main, Criterion, Throughput};
  use dat0_app::grid::renderers::render_cell;
  use duckdb::arrow::array::{
      Float64Builder, Int64Builder, StringBuilder, UInt64Builder,
  };
  use duckdb::arrow::datatypes::{DataType, Field, Schema};
  use duckdb::arrow::record_batch::RecordBatch;
  use std::sync::Arc;

  const ROWS: usize = 1_000_000;
  const VIEWPORT_ROWS: usize = 50; // typical visible rows per frame

  fn build_batch() -> RecordBatch {
      let mut i_b = Int64Builder::with_capacity(ROWS);
      let mut f_b = Float64Builder::with_capacity(ROWS);
      let mut s_b = StringBuilder::with_capacity(ROWS, ROWS * 8);
      let mut u_b = UInt64Builder::with_capacity(ROWS);
      for r in 0..ROWS {
          if r % 100 == 0 {
              i_b.append_null();
              f_b.append_null();
              s_b.append_null();
              u_b.append_null();
          } else {
              i_b.append_value(r as i64);
              f_b.append_value(r as f64 * 0.5);
              s_b.append_value(format!("r{}", r));
              u_b.append_value((r as u64).wrapping_mul(11));
          }
      }
      let schema = Arc::new(Schema::new(vec![
          Field::new("i", DataType::Int64, true),
          Field::new("f", DataType::Float64, true),
          Field::new("s", DataType::Utf8, true),
          Field::new("u", DataType::UInt64, true),
      ]));
      RecordBatch::try_new(
          schema,
          vec![
              Arc::new(i_b.finish()),
              Arc::new(f_b.finish()),
              Arc::new(s_b.finish()),
              Arc::new(u_b.finish()),
          ],
      )
      .unwrap()
  }

  fn bench_frame_render(c: &mut Criterion) {
      let batch = build_batch();
      let mut group = c.benchmark_group("grid_scroll");
      group.throughput(Throughput::Elements((VIEWPORT_ROWS as u64) * 4));
      group.bench_function("viewport_50rows_4cols", |b| {
          let mut row_cursor = 0usize;
          b.iter(|| {
              for r in row_cursor..(row_cursor + VIEWPORT_ROWS).min(ROWS) {
                  for c in 0..4 {
                      black_box(render_cell(&batch, c, r));
                  }
              }
              row_cursor = (row_cursor + VIEWPORT_ROWS) % (ROWS - VIEWPORT_ROWS);
          });
      });
      group.finish();
  }

  criterion_group!(benches, bench_frame_render);
  criterion_main!(benches);
  ```

  ```rust
  /// Scan `$state_root/scratch/*` for dirs not represented in the live
  /// registry. Returns the orphaned dirs (caller decides whether to
  /// recover or discard).
  pub fn scan_orphans(state_root: &Path, live: &[Uuid]) -> Result<Vec<PathBuf>> {
      let scratch_root = state_root.join("scratch");
      if !scratch_root.exists() {
          return Ok(Vec::new());
      }
      let live: std::collections::HashSet<Uuid> = live.iter().copied().collect();
      let mut orphans = Vec::new();
      for entry in std::fs::read_dir(&scratch_root)
          .with_context(|| format!("read_dir {}", scratch_root.display()))?
      {
          let entry = entry?;
          if !entry.file_type()?.is_dir() {
              continue;
          }
          let name = entry.file_name();
          let name_str = match name.to_str() {
              Some(s) => s,
              None => continue,
          };
          let id = match Uuid::parse_str(name_str) {
              Ok(id) => id,
              Err(_) => continue, // ignore non-UUID names
          };
          if !live.contains(&id) {
              orphans.push(entry.path());
          }
      }
      Ok(orphans)
  }
  ```

# dat0 P10c — Crash Reporting E2E + Settings Hardening — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take crash reporting end-to-end against the now-provisioned GlitchTip instance (real DSN + a relaunch crash dialog with a free-form note + a "Report a bug" action + hardened redaction + a soft CI round-trip gate), and pay off the D-029 settings/cleanup debt — without touching the still-deferred perf-gate runner or beta channel.

**Architecture:** The opt-in "flip" is already wired (`Telemetry::init(true)` → live `sentry::init` with `before_send` redaction). P10c adds (A) a process-lifetime **crash sentinel** + a **panic hook** that stages a redacted `last-crash.json` at panic time, then on next launch a **relaunch dialog** submits the staged event with the user's note via the now-healthy client; (B) the D-029 fixes. Logic is extracted into pure, headless-testable functions (GPUI render is UAT-verified, never unit-tested); the modal windows mirror the existing `view/name_prompt.rs` (InputState window) and `about::present` (`open_dialog`) patterns.

**Tech Stack:** Rust (workspace), `sentry = "0.36"` (features `backtrace, panic, rustls, reqwest`), `gpui = "=0.2.2"` + `gpui-component` (pinned `0f0ab35`), `serde`/`serde_json`, `clap` (xtask + cli), GitHub Actions.

```rust
// crates/dat0-app/src/telemetry/crash.rs
//! Crash sentinel + staged-crash payload.
//!
//! `running.marker` is created at boot and removed at clean shutdown; a marker
//! that survives into the next launch means the prior run exited abnormally.
//! `last-crash.json` carries a redacted panic payload staged by the panic hook
//! (see `mod.rs`), submitted on relaunch with the user's note.

use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};

#[derive(Serialize, Deserialize, Debug, Clone, PartialEq)]
pub struct StagedCrash {
    pub message: String,
    pub backtrace: String,
    pub version: String,
}

pub fn marker_path(data_dir: &Path) -> PathBuf {
    data_dir.join("running.marker")
}

pub fn staged_path(data_dir: &Path) -> PathBuf {
    data_dir.join("last-crash.json")
}

pub fn mark_running(data_dir: &Path) -> std::io::Result<()> {
    std::fs::write(marker_path(data_dir), b"1")
}

pub fn clear_running(data_dir: &Path) {
    let _ = std::fs::remove_file(marker_path(data_dir));
}

pub fn prior_crash_detected(data_dir: &Path) -> bool {
    marker_path(data_dir).exists()
}

pub fn write_staged(data_dir: &Path, crash: &StagedCrash) -> std::io::Result<()> {
    let json = serde_json::to_vec_pretty(crash)
        .map_err(|e| std::io::Error::new(std::io::ErrorKind::Other, e))?;
    std::fs::write(staged_path(data_dir), json)
}

pub fn read_staged(data_dir: &Path) -> Option<StagedCrash> {
    let bytes = std::fs::read(staged_path(data_dir)).ok()?;
    serde_json::from_slice(&bytes).ok()
}

pub fn clear_staged(data_dir: &Path) {
    let _ = std::fs::remove_file(staged_path(data_dir));
}
```

```rust
use crate::telemetry::redaction::redact_text_pub;

/// Build a redacted [`StagedCrash`] from a live panic. Pure (no I/O), so the
/// panic hook stays trivial and this is unit-testable.
pub fn payload_from_panic(info: &std::panic::PanicHookInfo<'_>, version: &str) -> StagedCrash {
    let raw_msg = info.to_string();
    let backtrace = std::backtrace::Backtrace::force_capture().to_string();
    StagedCrash {
        message: redact_text_pub(&raw_msg),
        backtrace: redact_text_pub(&backtrace),
        version: version.to_string(),
    }
}

/// Install a process-wide panic hook that stages a redacted crash payload, then
/// chains to the previously-installed hook (preserving default abort/print).
pub fn install_panic_hook(data_dir: PathBuf) {
    let prev = std::panic::take_hook();
    let version = env!("CARGO_PKG_VERSION").to_string();
    std::panic::set_hook(Box::new(move |info| {
        let payload = payload_from_panic(info, &version);
        let _ = write_staged(&data_dir, &payload);
        prev(info);
    }));
}
```

```rust
use sentry::protocol::{Event, Level, Value};

/// True when a live Sentry client is bound (telemetry opt-in is on).
pub fn is_active() -> bool {
    sentry::Hub::current().client().is_some()
}

fn capture(level: Level, kind: &str, message: String, note: Option<&str>, release: Option<&str>) {
    if !is_active() {
        return;
    }
    let mut event = Event {
        level,
        message: Some(message),
        ..Default::default()
    };
    event.tags.insert("kind".into(), kind.into());
    if let Some(r) = release {
        event.release = Some(r.to_string().into());
    }
    if let Some(n) = note {
        event.extra.insert("user_note".into(), Value::String(n.to_string()));
    }
    sentry::capture_event(event); // before_send redaction still applies
    sentry::Hub::current().client().map(|c| c.flush(Some(std::time::Duration::from_secs(5))));
}

/// Submit a staged crash (with optional user note). No-op when inactive.
pub fn submit_staged(crash: &crash::StagedCrash, note: Option<&str>) {
    capture(Level::Error, "crash", crash.message.clone(), note, Some(&crash.version));
}

/// Submit a user-initiated bug report. No-op when inactive.
pub fn submit_report(note: &str) {
    capture(Level::Info, "report-a-bug", "User bug report".to_string(), Some(note), None);
}
```

```rust
use std::path::{Path, PathBuf};

/// RAII guard: marks the run "in progress" + installs the crash-staging panic
/// hook on `arm`, and removes the running marker on `Drop` (clean shutdown).
/// A marker that survives into the next launch signals an unclean exit.
pub struct CrashGuard {
    data_dir: PathBuf,
}

impl CrashGuard {
    pub fn arm(data_dir: &Path) -> std::io::Result<Self> {
        crate::telemetry::crash::mark_running(data_dir)?;
        crate::telemetry::crash::install_panic_hook(data_dir.to_path_buf());
        Ok(Self { data_dir: data_dir.to_path_buf() })
    }
}

impl Drop for CrashGuard {
    fn drop(&mut self) {
        crate::telemetry::crash::clear_running(&self.data_dir);
    }
}
```

```rust
pub fn open_report(cx: &mut App, kind: ReportKind, data_dir: PathBuf) {
    let title = dat0_i18n::t(dialog_title_key(&kind));
    let body = dat0_i18n::t(dialog_body_key(&kind));
    let send = dat0_i18n::t("report.dialog.send");
    let kind = Rc::new(kind);
    let data_dir = Rc::new(data_dir);

    if let Some(handle) = cx.active_window() {
        let _ = handle.update(cx, move |_root: AnyView, window: &mut Window, cx| {
            // Create the note input entity BEFORE the Fn dialog builder.
            let note = cx.new(|cx| {
                gpui_component::input::InputState::new(window, cx)
                    .placeholder(dat0_i18n::t("report.dialog.note_placeholder"))
            });
            let (kind, data_dir, note2) = (kind.clone(), data_dir.clone(), note.clone());
            window.open_dialog(cx, move |dialog, _w, _cx| {
                let (kind, data_dir, note3) = (kind.clone(), data_dir.clone(), note2.clone());

                    .child(body.clone())

                    .button_props(
                        gpui_component::dialog::DialogButtonProps::default().ok_text(send.clone()),

                    .on_cancel({
                        let data_dir = data_dir.clone();
                        move |_ev, _w, cx| {
                            crash::clear_staged(&data_dir); // dismissed → discard
                            true
                        }
                    })
                    .on_ok(move |_ev, _w, cx| {
                        let text = note3.read(cx).value().to_string();

                        match kind.as_ref() {
                            ReportKind::Crash(staged) => {

                            }
                            ReportKind::Bug => {
                                telemetry::submit_report(note_opt.as_deref().unwrap_or(""))
                            }
                        }
                        crash::clear_staged(&data_dir);
                        true
                    })
            });
        });
    }
}
```

```yaml
name: crash-e2e
on:
  workflow_dispatch: {}
  push:
    branches: [main]
jobs:
  glitchtip-roundtrip:
    runs-on: ubuntu-latest
    continue-on-error: true   # D4: live external dep — must not redden main (ai_live lesson)
    env:
      DAT0_GLITCHTIP_DSN_PUBLIC: ${{ secrets.GLITCHTIP_DSN_PUBLIC }}
      GLITCHTIP_API_TOKEN: ${{ secrets.GLITCHTIP_API_TOKEN }}
      GLITCHTIP_PROJECT_SLUG: ${{ secrets.GLITCHTIP_PROJECT_SLUG }}
    steps:
      - uses: actions/checkout@v5
      - name: Skip if secrets absent
        id: gate
        run: |
          if [ -z "${DAT0_GLITCHTIP_DSN_PUBLIC}" ] || [ -z "${GLITCHTIP_API_TOKEN}" ]; then
            echo "secrets not set — skipping live e2e"; echo "run=false" >> "$GITHUB_OUTPUT"
          else
            echo "run=true" >> "$GITHUB_OUTPUT"
          fi
      - uses: dtolnay/rust-toolchain@stable
        if: steps.gate.outputs.run == 'true'
      - name: Build + send test event
        if: steps.gate.outputs.run == 'true'
        run: |
          cargo build -p dat0-app --release --bin dat0
          ./target/release/dat0 __telemetry-test
      - name: Assert arrival in GlitchTip + no PII
        if: steps.gate.outputs.run == 'true'
        run: |
          sleep 15  # ingestion lag
          BASE="${GLITCHTIP_API_URL:-https://app.glitchtip.com}"
          RESP=$(curl -sf -H "Authorization: Bearer ${GLITCHTIP_API_TOKEN}" \
            "${BASE}/api/0/projects/${GLITCHTIP_PROJECT_SLUG}/issues/?query=dat0+telemetry+e2e")
          echo "$RESP" | grep -q "dat0 telemetry e2e" || { echo "test event not found"; exit 1; }
          echo "$RESP" | grep -qE '/Users/|/home/' && { echo "PII leaked"; exit 1; } || true
          echo "round-trip OK"
```

# dat0 P8 — `.dat0` format + Package mode — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a dat0 workspace a shareable, replayable `.dat0` package (single zip: Parquet data cache + canonical recipe/sources/views/queries JSON), with a writer, read-only Inspect mode, unpack-to-workspace, replay-on-new-source, and a `dat0 diff` CLI.

**Architecture:** A new pure `dat0-format` crate (no GPUI; depends on `dat0-engine`) holds the package model types, JSON Schema, zip Writer/Reader, pure-JSON DiffEngine, and a ReplayEngine that re-runs the recipe DAG against new sources via a `&dyn QueryEngine`. The CLI is a subcommand front-door on the existing `dat0` binary (`dat0-app/src/main.rs`) that branches **before** GPUI init and delegates to `dat0-format`. In-app Export / Open(Inspect) / Unpack / Replay live in `dat0-app`, which maps its `Session`/`Tab`/`SavedQuery` state to the format crate's model. Inspect mode reuses the existing workspace shell behind a new `read_only` flag, registering the package's Parquet as `read_parquet` views.

**Tech Stack:** Rust, DuckDB (`duckdb` crate, bundled Arrow — **no standalone `arrow`/`parquet` dep**, CI-enforced), `zip`, `serde`/`serde_json`, `sha2`, `uuid` v7, `clap` (already in workspace), `jsonschema` (dev-only), GPUI + gpui-component for the UI.

**Phase split for execution:** Tasks T1 (model + JSON Schema + format doc) constitute the **P8a** ratification deliverable; T2–T10 are **P8b** Package mode. T0 spikes gate the unknowns first.

**Critical constraints (do not violate):**
- **Never** add `arrow = …` or `parquet = …` to any `Cargo.toml` (CI gate at `.github/workflows/ci.yml:212`). All Parquet I/O goes through `dat0_engine` (`COPY … TO (FORMAT PARQUET)` / `read_parquet`).
- The main DuckDB engine always opens read-write; Inspect read-only-ness comes from (a) registering data as **views** (`read_parquet`, non-mutable) and (b) the app-level `read_only` gate. There is no DuckDB read-only main-db mode in use.
- House gate before every commit: `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, and `./scripts/i18n-check.sh` if user-facing strings changed.
- Tests follow the house pattern: engine tests use `DuckDBEngine::new(dir.join("a.duckdb"), budget).init().await`; app tests use `Session::new(&state_root, BUDGET).await`. Always `engine.close().await` before drop. Test budgets are 128–256 MB, not 1 GB.

## Model types (defined once in T1, referenced everywhere)

These are the exact shapes later tasks depend on. `Transformation`, `DerivedOrigin`, `ColumnInfo` are `dat0_engine` types (already serde).

```rust
// crates/dat0-format/src/model.rs
use serde::{Deserialize, Serialize};
use dat0_engine::transform::Transformation;

pub const PACKAGE_KIND: &str = "package";

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct PackageManifest {
    pub format_version: u32,        // == crate::FORMAT_VERSION
    pub kind: String,               // PACKAGE_KIND
    pub dat0_version: String,
    pub package_id: uuid::Uuid,     // now_v7
    pub workspace_id: uuid::Uuid,   // origin workspace, provenance
    pub created_at: String,         // RFC3339
    pub table_count: u32,
    pub checksums: std::collections::BTreeMap<String, String>, // "data/sales.parquet" -> "sha256:…"
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct ColumnFingerprint { pub name: String, pub r#type: String } // DuckDB type literal

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum TableKind { Base, Derived }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Derivation {
    Sql { sql: String, parents: Vec<String> },
    Transform { parent: String, ops: Vec<Transformation> },
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct RecipeTable {
    pub id: String,                 // stable, e.g. "t_sales"
    pub name: String,               // DuckDB table name
    pub kind: TableKind,
    pub schema: Vec<ColumnFingerprint>,
    pub row_count: u64,
    pub data: String,               // "data/<name>.parquet"
    #[serde(skip_serializing_if = "Option::is_none")]
    pub source_ref: Option<String>, // base only -> PackageSource.id
    #[serde(skip_serializing_if = "Option::is_none")]
    pub derivation: Option<Derivation>, // derived only
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Recipe { pub tables: Vec<RecipeTable> }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct PackageSource {
    pub id: String,                 // "src_sales"
    pub logical_name: String,       // "sales.csv"
    pub original_uri: String,       // informational
    pub schema_fingerprint: Vec<ColumnFingerprint>,
    pub content_hash: String,       // sha256 of source bytes at export
    pub row_count: u64,
}
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Sources { pub sources: Vec<PackageSource> }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct PackageView {                 // mirrors dat0_app::session::Tab (portable subset)
    pub table_name: String,
    #[serde(default)] pub transform_stack: Vec<Transformation>,
    #[serde(default)] pub undo_cursor: usize,
}
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Views { pub views: Vec<PackageView> }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct PackageQuery { pub id: uuid::Uuid, pub name: String, pub sql: String, pub saved_at: i64 }
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Queries { pub queries: Vec<PackageQuery> }

/// Writer input — the portable contents, assembled by the app from a Session.
/// Data bytes are NOT here; the writer pulls them from `engine` per RecipeTable.name.
#[derive(Debug, Clone)]
pub struct PackageContents {
    pub workspace_id: uuid::Uuid,
    pub created_at: String,
    pub recipe: Recipe,
    pub sources: Sources,
    pub views: Views,
    pub queries: Queries,
}

/// Reader output.
#[derive(Debug, Clone)]
pub struct ParsedPackage {
    pub manifest: PackageManifest,
    pub recipe: Recipe,
    pub sources: Sources,
    pub views: Views,
    pub queries: Queries,
    pub(crate) zip_path: std::path::PathBuf, // for lazy data extraction
}
```

```rust
async fn parquet_roundtrip_preserves_types() {
    let dir = tempfile::tempdir().unwrap();
    let engine = DuckDBEngine::new(dir.path().join("a.duckdb"), budget()).unwrap();
    engine.init().await.unwrap();
    // Mixed types incl the gotchas: DECIMAL, NULL, DATE, TIMESTAMP, BIGINT.
    engine.execute(
        "CREATE TABLE t AS SELECT * FROM (VALUES \
         (1::BIGINT, 25.50::DECIMAL(9,2), DATE '2026-01-01', TIMESTAMP '2026-01-01 12:00:00'), \
         (2::BIGINT, NULL,                NULL,              NULL)) \
         AS v(id, amt, d, ts)").await.unwrap();
    let pq = dir.path().join("t.parquet");
    engine.export_query_to_path("SELECT * FROM t", ExportFormat::Parquet, &pq).await.unwrap();
    engine.execute(&format!(
        "CREATE VIEW rt AS SELECT * FROM read_parquet('{}')", pq.display())).await.unwrap();
    // Schema literals must match.
    let cols = engine.describe_table("rt", None).await.unwrap();
    let types: Vec<_> = cols.iter().map(|c| (c.name.as_str(), c.data_type.as_str())).collect();

    assert!(types.iter().any(|(n, t)| *n == "amt" && t.starts_with("DECIMAL(9,2)")), "got {types:?}");
    assert!(types.contains(&("d", "DATE")), "got {types:?}");
    // Values + NULLs survive.
    let r = engine.execute("SELECT amt::TEXT FROM rt WHERE id = 1").await.unwrap();
    assert_eq!(dat0_engine::test_support::first_cell(&r), "25.50"); // see Step 1a
    engine.close().await.unwrap();
}
```

- [ ] **Step 11: Author `docs/dat0-format-v1.md` (the ratified spec — P8a exit)**

Write a complete normative spec with these sections and explicit MUST statements:
- **§1 Scope & terminology** — `.dat0` *file* (package, this doc) vs `.dat0/` *directory* (workspace, P7). A package is an immutable zip.
- **§2 Container** — zip; JSON entries stored Deflated, `data/*.parquet` Stored. Required entries: `manifest.json`, `recipe.json`, `sources.json`, `views.json`, `queries.json`, `data/`. Readers MUST reject a package missing `manifest.json`.
- **§3 manifest.json** — link the published JSON Schema; field table; `format_version` MUST be 1 for this spec; `kind` MUST be `"package"`; `checksums` MUST cover every `data/*.parquet` entry and `recipe.json` as `sha256:<hex>`.
- **§4 recipe.json (canonical)** — `RecipeTable` fields; base tables MUST carry `source_ref`; derived MUST carry `derivation`; `data` materialized Parquet is a regenerable cache, recipe is authoritative.
- **§5 sources.json** — `schema_fingerprint` drives replay compat (§8); `content_hash` is sha256 of source bytes at export.
- **§6 views.json / queries.json** — overlays (`transform_stack`) reapplied via the producing engine; saved queries are informational + restored on unpack.
- **§7 Data files** — one Parquet per `RecipeTable.name`; written by DuckDB `COPY … TO (FORMAT PARQUET)`; readable by any Parquet/Arrow consumer (cross-language). dat0 reads via `read_parquet`.
- **§8 Replay compatibility** — structural / referenced-columns rule: a replacement source MUST provide every column the recipe references, matched by **name**, with a type-compatible DuckDB type; extra columns ignored; order irrelevant. Otherwise readers MUST refuse with a schema-diff.
- **§9 Versioning & compatibility** — semantic: **dat0 1.x reads format 1.x.** Unknown JSON fields ignored on read; missing optional fields default. A `format_version` whose major exceeds the reader's MUST be refused with a clear message.
- **§10 Non-goals (v1)** — no encryption, signing, delta/incremental, or merge.
- **§11 Cross-language reading** — Parquet + self-describing tagged JSON (cite the PD-014 tagged-wire convention); a non-Rust reader can route on `kind`/`tag` discriminators.

Include the manifest JSON example and one full `recipe.json` example from the design doc. Add a note that the `dat0.dev/format/v1` mirror is a P11 deliverable.

- [ ] **Step 3: Implement `src/writer.rs`**

`Writer::write` is `async` (it awaits engine COPY). Algorithm: for each `RecipeTable`, `engine.export_query_to_path("SELECT * FROM \"<name>\"", ExportFormat::Parquet, tmp)` into a tempdir; read bytes; sha256; add to zip as `data/<name>.parquet` (Stored); accumulate checksum. Serialize `recipe/sources/views/queries` to pretty JSON, sha256 `recipe.json`, add (Deflated). Build `PackageManifest` (format_version = FORMAT_VERSION, kind = PACKAGE_KIND, dat0_version = `env!("CARGO_PKG_VERSION")`, package_id = now_v7, table_count, checksums) and add as `manifest.json` last.

```rust
use std::io::Write;
use std::path::Path;
use sha2::{Digest, Sha256};
use zip::write::SimpleFileOptions;
use dat0_engine::{QueryEngine, types::ExportFormat};
use crate::{model::*, FORMAT_VERSION, error::{FormatError, Result}};

pub struct Writer;
impl Writer {
    pub async fn write(contents: &PackageContents, engine: &dyn QueryEngine, dest: &Path) -> Result<()> {
        let tmp = tempfile::tempdir().map_err(|e| FormatError::Io { path: dest.into(), source: e })?;
        let file = std::fs::File::create(dest).map_err(|e| FormatError::Io { path: dest.into(), source: e })?;
        let mut zip = zip::ZipWriter::new(file);
        let stored = SimpleFileOptions::default().compression_method(zip::CompressionMethod::Stored);
        let deflated = SimpleFileOptions::default().compression_method(zip::CompressionMethod::Deflated);
        let mut checksums = std::collections::BTreeMap::new();

        for t in &contents.recipe.tables {
            let pq = tmp.path().join(format!("{}.parquet", t.name));
            let select = format!("SELECT * FROM {}", dat0_engine::catalog::quote_ident(&t.name));
            engine.export_query_to_path(&select, ExportFormat::Parquet, &pq).await?;
            let bytes = std::fs::read(&pq).map_err(|e| FormatError::Io { path: pq.clone(), source: e })?;
            let entry = t.data.clone(); // "data/<name>.parquet"
            zip.start_file(&entry, stored)?;
            zip.write_all(&bytes).map_err(|e| FormatError::Io { path: pq.clone(), source: e })?;
            checksums.insert(entry, format!("sha256:{:x}", Sha256::digest(&bytes)));
        }

        // recipe.json (checksummed) + the other JSON entries.
        let recipe_bytes = serde_json::to_vec_pretty(&contents.recipe)?;
        checksums.insert("recipe.json".into(), format!("sha256:{:x}", Sha256::digest(&recipe_bytes)));
        write_json(&mut zip, "recipe.json", &recipe_bytes, deflated)?;
        write_json(&mut zip, "sources.json", &serde_json::to_vec_pretty(&contents.sources)?, deflated)?;
        write_json(&mut zip, "views.json", &serde_json::to_vec_pretty(&contents.views)?, deflated)?;
        write_json(&mut zip, "queries.json", &serde_json::to_vec_pretty(&contents.queries)?, deflated)?;

        let manifest = PackageManifest {
            format_version: FORMAT_VERSION, kind: PACKAGE_KIND.into(),
            dat0_version: env!("CARGO_PKG_VERSION").into(),
            package_id: uuid::Uuid::now_v7(), workspace_id: contents.workspace_id,
            created_at: contents.created_at.clone(),
            table_count: contents.recipe.tables.len() as u32, checksums,
        };
        write_json(&mut zip, "manifest.json", &serde_json::to_vec_pretty(&manifest)?, deflated)?;
        zip.finish()?;
        Ok(())
    }
}
fn write_json(zip: &mut zip::ZipWriter<std::fs::File>, name: &str, bytes: &[u8], opt: zip::write::SimpleFileOptions) -> Result<()> {
    zip.start_file(name, opt)?;
    zip.write_all(bytes).map_err(|e| FormatError::Io { path: name.into(), source: e })?;
    Ok(())
}
```

- [ ] **Step 3: Implement `src/reader.rs`**

`Reader::open` (sync): open zip, read `manifest.json`, **check `manifest.format_version == FORMAT_VERSION`** (major check; on mismatch return `UnsupportedVersion`), read the four JSON entries into the model, verify each `data/*.parquet` and `recipe.json` checksum against `manifest.checksums` (return `ChecksumMismatch` on first mismatch). Store `zip_path` for lazy extraction. `extract_data_to(dir)` re-opens the zip and writes every `data/*` entry under `dir`.

```rust
use std::io::Read;
use std::path::{Path, PathBuf};
use sha2::{Digest, Sha256};
use crate::{model::*, FORMAT_VERSION, error::{FormatError, Result}};

pub struct Reader;
impl Reader {
    pub fn open(path: &Path) -> Result<ParsedPackage> {
        let file = std::fs::File::open(path).map_err(|e| FormatError::Io { path: path.into(), source: e })?;
        let mut zip = zip::ZipArchive::new(file)?;
        let manifest: PackageManifest = read_json(&mut zip, "manifest.json")?;
        if manifest.format_version != FORMAT_VERSION {
            return Err(FormatError::UnsupportedVersion { found: manifest.format_version, supported: FORMAT_VERSION });
        }
        let recipe: Recipe = read_json(&mut zip, "recipe.json")?;
        let sources: Sources = read_json(&mut zip, "sources.json")?;
        let views: Views = read_json(&mut zip, "views.json")?;
        let queries: Queries = read_json(&mut zip, "queries.json")?;
        // Verify checksums.
        for (entry, expected) in &manifest.checksums {
            let mut f = zip.by_name(entry)?;
            let mut buf = Vec::new();
            f.read_to_end(&mut buf).map_err(|e| FormatError::Io { path: entry.into(), source: e })?;
            let got = format!("sha256:{:x}", Sha256::digest(&buf));
            if &got != expected { return Err(FormatError::ChecksumMismatch { entry: entry.clone() }); }
        }
        Ok(ParsedPackage { manifest, recipe, sources, views, queries, zip_path: path.to_path_buf() })
    }
}
impl ParsedPackage {
    pub fn extract_data_to(&self, dir: &Path) -> Result<()> {
        let file = std::fs::File::open(&self.zip_path).map_err(|e| FormatError::Io { path: self.zip_path.clone(), source: e })?;
        let mut zip = zip::ZipArchive::new(file)?;
        for i in 0..zip.len() {
            let mut f = zip.by_index(i)?;
            let name = f.name().to_string();
            if let Some(rest) = name.strip_prefix("data/") {
                let out = dir.join("data").join(rest);
                std::fs::create_dir_all(out.parent().unwrap()).ok();
                let mut buf = Vec::new();
                f.read_to_end(&mut buf).map_err(|e| FormatError::Io { path: out.clone(), source: e })?;
                std::fs::write(&out, &buf).map_err(|e| FormatError::Io { path: out, source: e })?;
            }
        }
        Ok(())
    }
}
fn read_json<T: serde::de::DeserializeOwned>(zip: &mut zip::ZipArchive<std::fs::File>, name: &str) -> Result<T> {
    let mut f = zip.by_name(name)?;
    let mut s = String::new();
    f.read_to_string(&mut s).map_err(|e| FormatError::Io { path: name.into(), source: e })?;
    Ok(serde_json::from_str(&s)?)
}
```

Map the live session to `PackageContents`:

For `Derived(DerivedOrigin::Sql(sql))` → `Derivation::Sql { sql, parents: engine.referenced_tables(&sql).await? }`; for `Transform { parent, ops }` → `Derivation::Transform { parent, ops }`; set `source_ref` for base tables that have a `File` origin.
- `sources` from base `File(path)` origins: `PackageSource { id: format!("src_{name}"), logical_name: file_name, original_uri: path, schema_fingerprint: schema, content_hash: sha256(file bytes if readable else ""), row_count }`.
- `views` from `sess.tabs()` → `PackageView { table_name, transform_stack, undo_cursor }`.
- `queries` from `sess.saved_queries()` → `PackageQuery { id, name, sql, saved_at }`.
- `workspace_id` = read `.dat0/manifest.json` if workspace, else `Uuid::now_v7()`; `created_at` = `now_rfc3339()` (reuse the app's existing time helper used by `Manifest::new`).

```rust
use dat0_engine::QueryEngine;
use dat0_engine::types::{TableOrigin, DerivedOrigin};
use dat0_format::*;
use crate::session::Session;

pub async fn session_to_contents(sess: &Session) -> anyhow::Result<PackageContents> {
    let engine = sess.engine.as_ref();
    let tables = engine.get_tables().await?;
    let mut recipe = Vec::new();
    let mut sources = Vec::new();
    for t in &tables {
        if t.name.starts_with("__") { continue; } // skip internal surrogates if any surface
        let schema: Vec<ColumnFingerprint> = t.columns.iter()
            .map(|c| ColumnFingerprint { name: c.name.clone(), r#type: c.data_type.clone() }).collect();
        let row_count = count_rows(engine, &t.name).await?;
        let data = format!("data/{}.parquet", t.name);
        let (kind, source_ref, derivation) = match &t.origin {
            TableOrigin::File(path) => {
                let id = format!("src_{}", t.name);
                sources.push(make_source(&id, path, &schema, row_count));
                (TableKind::Base, Some(id), None)
            }
            TableOrigin::Attached { .. } => (TableKind::Base, None, None),
            TableOrigin::Derived(DerivedOrigin::Sql(sql)) => {
                let parents = engine.referenced_tables(sql).await.unwrap_or_default();
                (TableKind::Derived, None, Some(Derivation::Sql { sql: sql.clone(), parents }))
            }
            TableOrigin::Derived(DerivedOrigin::Transform { parent, ops }) =>
                (TableKind::Derived, None, Some(Derivation::Transform { parent: parent.clone(), ops: ops.clone() })),
        };
        recipe.push(RecipeTable { id: format!("t_{}", t.name), name: t.name.clone(), kind, schema, row_count, data, source_ref, derivation });
    }
    let views = sess.tabs().iter().map(|tab| PackageView {
        table_name: tab.table_name.clone(), transform_stack: tab.transform_stack.clone(), undo_cursor: tab.undo_cursor,
    }).collect();
    let queries = sess.saved_queries().iter().map(|q| PackageQuery {
        id: q.id, name: q.name.clone(), sql: q.sql.clone(), saved_at: q.saved_at,
    }).collect();
    Ok(PackageContents {
        workspace_id: sess.workspace_id_or_new(),       // helper: manifest id or now_v7
        created_at: crate::workspace::now_rfc3339(),     // reuse existing time helper
        recipe: Recipe { tables: recipe },
        sources: Sources { sources },
        views: Views { views },
        queries: Queries { queries },
    })
}
```

# dat0 P10b — Hardening (a11y + Settings completeness + privacy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Discharge the P10b hardening slice — an automated WCAG contrast gate, a real (no-longer-stub) Settings window covering all nine §24.2 sections with working widgets, and the privacy docs — so the P10 a11y + Settings-completeness + privacy exit criteria pass.

**Architecture:** Three independent workstreams. (A) A pure `theme::contrast` module + a CI gate test over the three builtin themes. (B) Replace the never-mounted `open_settings_window` stub with a stateful `SettingsPanel` GPUI window holding real `Button` / `InputState` / DIY-toggle / `Button`-cycle widgets across nine registered sections; the existing store-only `set_*` persistence functions are reused unchanged. (C) Author `docs/a11y.md`, `docs/privacy.md`, `docs/privacy-review-process.md`. A T0-style spike-scaffold task (T4) frontloads the GPUI window/widget risk before the per-section tasks.

**Tech Stack:** Rust; `gpui =0.2.2`; `gpui-component` v0.5.1 (rev `0f0ab35`); DuckDB via `duckdb-rs`; `tracing` / `tracing-subscriber`; `serde` / `toml`; `dat0-i18n`.

## Global Constraints

- **Pinned UI deps — no new primitives:** `gpui =0.2.2`, `gpui-component` rev `0f0ab35`. **No `Switch`/`Checkbox`** and **no ergonomic `Select`** exist — use DIY toggles (`div().id().on_click()`, the `connections/panel.rs` `action_button` pattern) and `Button` cycles (the `window.rs:3467` chart-type pattern). `Button` and `InputState` are the only ready widgets.
- **`InputState` lifecycle:** construct eagerly with `&mut Window` inside `cx.new(|cx| InputState::new(window, cx)…)`, store as `Entity<InputState>`, read via `.read(cx).value()`.
- **`Root` wrapper mandatory** for any window that opens dialogs: build view, then `cx.new(|cx| Root::new(view, window, cx))`; mount `Root::render_dialog_layer(window, cx)` in the panel render or the confirm dialog paints nothing.
- **Dialog body needs `use gpui::ParentElement as _;`** in scope (else `E0599 no method named child`).
- **All user-visible strings** go through `dat0_i18n::t("key")` with the key added to `crates/dat0-i18n/src/strings/en.json` (flat keys). The `i18n-check` CI gate fails on a missing key.
- **DCO:** every commit signed off (`git commit --signoff`).
- **Workspace gate (must pass before merge):** `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace`, `i18n-check`.
- **Settings TOML schema:** the `Settings` struct uses `#[serde(default)]`; new fields are serde-defaulted, so **no `schema_version` bump and no migration** are needed (old `settings.toml` files load fine).
- **GPUI render correctness is verified by manual UAT**, not headless tests (no AccessKit/introspection). Headless tests cover persistence round-trips, the section registry, and the contrast math.

```rust
//! WCAG 2.1 relative-luminance + contrast-ratio math over `#rrggbb` hex
//! strings. Pure (no GPUI), so the a11y gate test runs headless in CI.

/// Parse `#rrggbb` into linearized sRGB relative luminance (WCAG 2.1 §def).
pub fn relative_luminance(hex: &str) -> f64 {
    let h = hex.trim_start_matches('#');
    let r = u8::from_str_radix(&h[0..2], 16).unwrap_or(0);
    let g = u8::from_str_radix(&h[2..4], 16).unwrap_or(0);
    let b = u8::from_str_radix(&h[4..6], 16).unwrap_or(0);
    fn lin(c: u8) -> f64 {
        let c = c as f64 / 255.0;
        if c <= 0.03928 { c / 12.92 } else { ((c + 0.055) / 1.055).powf(2.4) }
    }
    0.2126 * lin(r) + 0.7152 * lin(g) + 0.0722 * lin(b)
}

/// WCAG contrast ratio between two `#rrggbb` colors, in `[1.0, 21.0]`.
pub fn contrast_ratio(a: &str, b: &str) -> f64 {
    let (la, lb) = (relative_luminance(a), relative_luminance(b));
    let (hi, lo) = if la >= lb { (la, lb) } else { (lb, la) };
    (hi + 0.05) / (lo + 0.05)
}

#[cfg(test)]
mod tests {

    #[test]
    fn black_on_white_is_21() {
        assert!((contrast_ratio("#000000", "#ffffff") - 21.0).abs() < 0.01);

    #[test]
    fn known_pairs_match_reference() {
        // dark fg/bg, computed reference = 12.25:1
        assert!((contrast_ratio("#c9d1d9", "#0e1116") - 12.25).abs() < 0.05);
        // light warning/bg, the tightest passing pair = 4.87:1

        // order-independent
```

```rust
//! WCAG AA contrast gate over the three builtin themes (P10b a11y).
//! Fails CI if any required fg/bg pair drops below threshold. `border`
//! is intentionally exempt (decorative; WCAG 1.4.11 carve-out).

use dat0_app::theme::{Theme, contrast::contrast_ratio};

fn style_color<'a>(t: &'a Theme, name: &str) -> &'a str {
    match name {
        "background" => &t.style.background,
        "foreground" => &t.style.foreground,
        "accent" => &t.style.accent,
        "error" => &t.style.error,
        "success" => &t.style.success,
        "warning" => &t.style.warning,
        "selection_fg" => t.selection_fg(), // branch B only
        other => panic!("unknown token {other}"),
    }
}

#[test]
fn builtin_themes_meet_wcag_aa() {
    // (token_a, token_b, min_ratio)
    let matrix: &[(&str, &str, f64)] = &[
        ("foreground", "background", 4.5),
        ("error", "background", 4.5),
        ("success", "background", 4.5),
        ("warning", "background", 4.5),
        ("accent", "background", 4.5),
        ("selection_fg", "accent", 4.5), // branch B; branch A: ("accent","background",3.0)
    ];
    let mut failures = vec![];
    for name in ["light", "dark", "high-contrast"] {
        let t = Theme::load_builtin(name).expect("builtin parses");
        for (a, b, min) in matrix {
            let r = contrast_ratio(style_color(&t, a), style_color(&t, b));
            if r < *min {
                failures.push(format!("{name}: {a}/{b} = {r:.2}:1 < {min}"));
            }
        }
    }
    assert!(failures.is_empty(), "WCAG AA contrast failures:\n{}", failures.join("\n"));
}
```

```rust
//! Stateful Settings window entity (P10b — discharges the deferred "T13").
//! Holds the InputState widgets + selected section; renders the sidebar from
//! `sections::all_sections()` and dispatches to per-section render methods.

use super::sections;
use crate::settings::store::SettingsStore;
use crate::theme::Theme;
use gpui::{Entity, IntoElement, ParentElement as _, Render, Styled as _, Window, div, prelude::*, px};
use gpui_component::Root;
use gpui_component::input::{Input, InputState};

pub struct SettingsPanel {
    selected_section: String,
    name_input: Entity<InputState>,
    email_input: Entity<InputState>,
    store: SettingsStore,
}

impl SettingsPanel {
    pub fn new(store: SettingsStore, window: &mut Window, cx: &mut gpui::Context<Self>) -> Self {
        let name0 = store.get_string("author.name").unwrap_or_default();
        let email0 = store.get_string("author.email").unwrap_or_default();
        let name_input = cx.new(|cx| InputState::new(window, cx).default_value(name0));
        let email_input = cx.new(|cx| InputState::new(window, cx).default_value(email0));
        Self { selected_section: "profile".into(), name_input, email_input, store }
    }

    fn render_sidebar(&self, cx: &mut gpui::Context<Self>) -> impl IntoElement {
        let sel = self.selected_section.clone();
        div().w_64().flex().flex_col().children(sections::all_sections().into_iter().map(|s| {
            let id = s.id().to_string();
            let active = id == sel;
            div()
                .id(gpui::SharedString::from(id.clone()))
                .cursor_pointer()
                .px_3().py_1()
                .when(active, |d| d.bg(cx.global::<Theme>().style.accent.clone()))
                .child(dat0_i18n::t(s.name_key()))
                .on_click(cx.listener(move |this, _ev, _w, cx| {
                    this.selected_section = id.clone();
                    cx.notify();
                }))
        }))
    }

    fn render_profile(&self, _cx: &mut gpui::Context<Self>) -> impl IntoElement {
        div().flex().flex_col().gap_2().p_3()
            .child(dat0_i18n::t("settings.profile.placeholder"))
            .child(Input::new(&self.name_input))
            .child(Input::new(&self.email_input))
    }

    fn persist_profile(&self, cx: &gpui::App) {
        let name = self.name_input.read(cx).value().to_string();
        let email = self.email_input.read(cx).value().to_string();
        let _ = sections::profile::ProfileSection::on_name_change(&self.store, &name);
        let _ = sections::profile::ProfileSection::on_email_change(&self.store, &email);
    }
}

impl Render for SettingsPanel {
    fn render(&mut self, window: &mut Window, cx: &mut gpui::Context<Self>) -> impl IntoElement {
        // Persist Profile inputs on each render tick (cheap; values are short).
        self.persist_profile(cx);
        let content = match self.selected_section.as_str() {
            "profile" => self.render_profile(cx).into_any_element(),
            _ => div().p_3().child(dat0_i18n::t("settings.section.placeholder")).into_any_element(),
        };
        div().flex().flex_row().size_full()
            .child(self.render_sidebar(cx))
            .child(div().flex_1().child(content))
            // Mandatory: dialog layer for the Reset confirm (T9). Sheet layer
            // not needed here but harmless to mount.
            .children(Root::render_dialog_layer(window, cx))
    }
}
```

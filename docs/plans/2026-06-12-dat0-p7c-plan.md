# P7c — Live data + recovery polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch the active imported table's source file and, on external change, offer a one-click re-import that replays the tab's structural transforms; finish the recovery Sheet UI (orphan scratch + interrupted workspace); and render banner action buttons (closes D-021).

**Architecture:** Per-`WorkspaceShell` `notify` watcher over the active `view_model`'s `source_path` (re-targeted on table switch). A debounced change raises a Refresh banner; clicking it splits the transform stack (column-keyed ops replay, rowid-keyed ops are confirm-discarded), re-CTAS via the existing `register_file_as_table`, and force-rebinds the grid through `apply_view_change`. The recovery Sheet mounts via the P7b active-window `update` hop and lists orphan-scratch + incomplete-workspace rows. Banners gain a real action button dispatched through the existing `ActionRegistry`.

**Tech Stack:** Rust, `notify` crate (file watch), gpui + gpui-component (`Sheet`, `Button`, `Dialog`, `WindowExt`), DuckDB (`register_file_as_table`), `dat0_i18n`.

## Discovered constraints (verified against live code 2026-06-12)

These refine the approved design (`docs/plans/2026-06-12-dat0-p7c-design.md`) without changing its decisions:

1. **Single live `view_model`.** `WorkspaceShell.view_model: Option<ViewModel>` (`window.rs:1043`) — one table mounted at a time; `open_table_tab` (`window.rs:1886`) rebuilds it. So the watch set is **the active table's source file**, re-targeted on switch. Multi-table simultaneous watching is a future extension (noted in T11 deferrals).
2. **`ViewModel` carries no `source_path`.** The table→path mapping is in `catalog_tables: Vec<TableInfo>` (`window.rs:1198`) via `TableOrigin::File(path)` and in session `Tab.source_path`. T5 resolves the active model's source by matching its `base_table()` against `catalog_tables`.
3. **`register_file_as_table` is idempotent** (`CREATE OR REPLACE TABLE`, `duckdb_engine.rs:230`) and re-derives the same `table_name` from the path → re-import refreshes the *same* base table in place; rowids regenerate.
4. **Replay must force a rebind.** `ViewModel::regenerate_view` (`view/model.rs:316`) has a display-only fast path that skips the engine hop when the compiled SQL is unchanged. After re-CTAS the base *data* changed, so refresh must clear `active_view_sql` to force a real re-read (T2).
5. **Banner is rendered by `render_banner`** (`error_ux/banner.rs`), a free fn returning `impl IntoElement`, hosted in `WorkspaceShell::render` (`window.rs:3314`). `Banner.primary: Option<BannerAction{label, action_id}>` already exists; only the button render+dispatch is missing (D-021).
6. **Action dispatch:** `ActionRegistry::get(&ActionId) -> Option<ActionDescriptor>`; `ActionDescriptor.dispatch: Arc<dyn Fn(&mut App)>`. Registry reachable via `window_registry::action_registry()`. The `recovery.review` descriptor already calls `recovery_panel::open(app)` (`actions/builtin.rs:143`).
7. **Sheet/Dialog hop (P7b-proven):** `cx.active_window()?.update(cx, |_root: AnyView, window: &mut Window, cx| window.open_sheet_at(Placement::Top, cx, |sheet,_w,_cx| …))`. Requires `use gpui_component::WindowExt as _;` and `use gpui::ParentElement as _;`. `Root::render_sheet_layer(window, cx)` must be mounted (verify in T8).
8. **Session stays v8** (D8) — no new persisted field. T0 confirms.

```rust
/// Partition of a transform stack for live re-import replay (P7c D3).
///
/// Column-keyed ops (`Filter`/`Sort`/`Reorder`/`Rename`/`DeleteColumn`) reference
/// column names and replay cleanly onto a re-imported base. Rowid-keyed ops
/// (`Edit`/`RowDelete`) reference `__dat0_rowid` surrogates that re-CTAS
/// regenerates, so they cannot be safely carried over and are dropped.
#[derive(Debug, Clone, PartialEq)]
pub struct ReplaySplit {
    pub replayable: Vec<Transformation>,
    pub dropped_edits: usize,
    pub dropped_deletes: usize,
}

impl ReplaySplit {
    pub fn has_dropped(&self) -> bool {
        self.dropped_edits > 0 || self.dropped_deletes > 0
    }
}

/// Split a transform stack into the column-keyed ops that survive a re-import
/// and counts of the rowid-keyed ops that must be discarded.
pub fn split_replayable(ops: &[Transformation]) -> ReplaySplit {
    let mut replayable = Vec::new();
    let mut dropped_edits = 0;
    let mut dropped_deletes = 0;
    for op in ops {
        match op {
            Transformation::Edit { cells } => dropped_edits += cells.len().max(1).min(1), // count the OP, not cells; see below
            Transformation::RowDelete { .. } => dropped_deletes += 1,
            other => replayable.push(other.clone()),
        }
    }
    ReplaySplit { replayable, dropped_edits, dropped_deletes }
}
```

> The test counts **one** dropped edit op. If you want to count edited *cells* instead, change the test + impl together. Keep it counting ops for a simpler user message ("N edits"); replace the awkward `.max(1).min(1)` with `dropped_edits += 1`.

```rust
/// Replace the active stack with `ops` and force a full grid rebind, used by
/// live re-import refresh (P7c). Unlike `apply`/`jump_to`, this ALWAYS emits a
/// data-rebinding `ViewChange` (never the display-only fast path) because the
/// underlying base-table data changed even when the compiled SQL is identical.
///
/// Clears undo/redo history: the re-imported base is a new data epoch, so the
/// pre-refresh history (which may reference dropped rowid edits) is no longer
/// meaningful.
pub fn reset_to_replayed(&mut self, ops: Vec<Transformation>) -> ViewChange {
    self.past.clear();
    self.future.clear();
    self.present = ops;
    // Force `regenerate_view` off its display-only fast path: the data changed.
    self.active_view_sql = None;
    self.regenerate_view()
}
```

```rust
//! Per-window file watcher over a single imported table's source file (P7c).
//!
//! Mirrors `settings/watcher.rs`: owns a `notify::RecommendedWatcher` whose
//! `Drop` stops watching. Adds a debounce so a burst of editor saves coalesces
//! into one `on_change` call. The callback must NOT touch GPUI state directly —
//! it runs on a `notify` background thread; the caller bridges to the main
//! thread via `MainThreadDispatcher` (see window.rs T5).

use anyhow::Result;
use notify::{EventKind, RecommendedWatcher, RecursiveMode, Watcher};
use std::path::PathBuf;
use std::sync::mpsc;
use std::time::Duration;

pub struct SourceWatcher {
    _watcher: RecommendedWatcher,
    _stop: mpsc::Sender<()>,
}

impl SourceWatcher {
    /// Watch `path`; call `on_change(path)` at most once per `debounce` quiet
    /// window after the last `Modify`/`Create` event.
    pub fn start<F>(path: PathBuf, debounce: Duration, on_change: F) -> Result<Self>
    where
        F: Fn(PathBuf) + Send + 'static,
    {
        let (evt_tx, evt_rx) = mpsc::channel::<()>();
        let (stop_tx, stop_rx) = mpsc::channel::<()>();
        let watch_path = path.clone();

        let mut watcher = notify::recommended_watcher(move |res: notify::Result<notify::Event>| {
            match res {
                Ok(event) if matches!(event.kind, EventKind::Modify(_) | EventKind::Create(_)) => {
                    let _ = evt_tx.send(());
                }
                Ok(_) => {}
                Err(e) => tracing::warn!(?e, "source watcher error"),
            }
        })?;
        watcher.watch(&watch_path, RecursiveMode::NonRecursive)?;

        // Debounce thread: collect events, fire `on_change` after a quiet window.
        std::thread::Builder::new()
            .name("dat0-source-debounce".into())
            .spawn(move || {
                loop {
                    // Block for the first event (or stop).
                    match evt_rx.recv() {
                        Ok(()) => {}
                        Err(_) => return, // watcher dropped
                    }
                    // Drain the quiet window: keep resetting while events arrive.
                    loop {
                        match evt_rx.recv_timeout(debounce) {
                            Ok(()) => continue,                 // more activity → keep waiting
                            Err(mpsc::RecvTimeoutError::Timeout) => break, // quiet → fire
                            Err(mpsc::RecvTimeoutError::Disconnected) => return,
                        }
                    }
                    if stop_rx.try_recv().is_ok() {
                        return;
                    }
                    on_change(path.clone());
                }
            })?;

        Ok(Self { _watcher: watcher, _stop: stop_tx })
    }
}
```

```rust
/// (Re)create the source watcher for the active table. Drops any previous
/// watch. No-op (clears the watch) if the active table has no File source.
pub(crate) fn retarget_source_watch(&mut self, cx: &mut Context<Self>) {
    let Some(path) = self.active_source_path() else {
        self.source_watcher = None;
        return;
    };
    if !path.exists() {
        self.source_watcher = None; // file gone → nothing to watch (D7 error row)
        return;
    }
    let ws = cx.entity().downgrade();
    let watcher = crate::workspace::source_watcher::SourceWatcher::start(
        path.clone(),
        std::time::Duration::from_millis(500),
        move |changed| {
            // notify thread → hop to GPUI main thread via the dispatcher.
            if let Some(d) = crate::window_registry::dispatcher() {
                let ws = ws.clone();
                let _ = d.dispatch(move |app| {
                    if let Some(h) = ws.upgrade() {
                        h.update(app, |shell, cx| shell.on_source_changed(changed, cx));
                    }
                });
            }
        },
    );
    match watcher {
        Ok(w) => self.source_watcher = Some(w),
        Err(e) => tracing::warn!(error = %e, "failed to start source watcher"),
    }
}

/// Raise a one-click Refresh banner for an externally-changed source file.
/// De-dups: if a refresh banner for this path is already present, do nothing.
pub(crate) fn on_source_changed(&mut self, path: std::path::PathBuf, cx: &mut Context<Self>) {
    let file = path.file_name().map(|s| s.to_string_lossy().to_string())
        .unwrap_or_else(|| path.display().to_string());
    let title = dat0_i18n::t("livedata.changed.title").replace("{file}", &file);
    let already = self.banners.iter().any(|b| b.title == title);
    if already {
        return;
    }
    self.banners.push(
        crate::error_ux::Banner::warning(title)
            .with_primary(dat0_i18n::t("livedata.changed.refresh"),
                          crate::actions::builtin::ids::LIVE_REFRESH),
    );
    cx.notify();
}
```

```rust
    /// transforms (P7c). If the stack has rowid-keyed edits, confirm-discard
    /// first via a blocking Dialog. Clears the refresh banner on success.
    pub(crate) fn run_refresh(&mut self, cx: &mut Context<Self>) {
        use dat0_engine::transform::split_replayable;
        let Some(path) = self.active_source_path() else { return; };
        let Some(vm) = self.view_model.as_ref() else { return; };
        let split = split_replayable(vm.stack());

        if split.has_dropped() {
            // Escalate to a confirm Dialog; on confirm, re-enter without edits.
            let body = dat0_i18n::t("livedata.refresh.confirm.body")
                .replace("{edits}", &split.dropped_edits.to_string())
                .replace("{deletes}", &split.dropped_deletes.to_string());
            let ws = cx.entity().downgrade();
            crate::live_refresh_dialog::confirm_discard(cx, body, move |app| {
                if let Some(h) = ws.upgrade() {
                    h.update(app, |shell, cx| shell.perform_reimport(cx));
                }
            });
        } else {
            self.perform_reimport(cx);
        }
    }

    /// Off-thread re-CTAS + on-main replay of the structural stack.
    pub(crate) fn perform_reimport(&mut self, cx: &mut Context<Self>) {
        use dat0_engine::transform::split_replayable;
        let Some(path) = self.active_source_path() else { return; };
        let Some(vm) = self.view_model.as_ref() else { return; };
        let replayable = split_replayable(vm.stack()).replayable;
        let engine = self.engine();
        let ws = cx.entity().downgrade();
        let banner_title_file = path.file_name().map(|s| s.to_string_lossy().to_string());

        tokio::spawn(async move {
            let opts = dat0_engine::RegisterOpts::default();
            let result = engine.register_file_as_table(&path, opts).await;
            if let Some(d) = crate::window_registry::dispatcher() {
                let _ = d.dispatch(move |app| {
                    let Some(h) = ws.upgrade() else { return; };
                    h.update(app, |shell, cx| {
                        match result {
                            Ok(_info) => shell.apply_refresh_replay(replayable, banner_title_file, cx),
                            Err(e) => {
                                tracing::warn!(error = %e, "re-import failed");
                                shell.banners.push(crate::error_ux::Banner::error(
                                    dat0_i18n::t("livedata.reimport.failed.title"),
                                    format!("{e}"),
                                ));
                                cx.notify();
                            }
                        }
                    });
                });
            }
        });
    }

    /// On the main thread: replay the structural ops via the force-rebind
    /// primitive, drive the engine round-trip, clear the refresh banner.
    pub(crate) fn apply_refresh_replay(
        &mut self,
        replayable: Vec<dat0_engine::transform::Transformation>,
        file: Option<String>,
        cx: &mut Context<Self>,
    ) {
        let Some(vm) = self.view_model.as_mut() else { return; };
        let change = vm.reset_to_replayed(replayable);
        let base = vm.base_table().to_string();
        let engine = self.engine();
        let ws = cx.entity().downgrade();
        crate::view::spawn_view_change(engine, base, change, std::sync::Arc::new(
            move |new_ds, app_cx| {
                if let Some(h) = ws.upgrade() {
                    h.update(app_cx, |shell, cx| shell.apply_view_change(new_ds, cx));
                }
            },
        ));
        // Drop the refresh banner(s) for this file + toast success.
        if let Some(file) = file {
            let title = dat0_i18n::t("livedata.changed.title").replace("{file}", &file);
            self.banners.retain(|b| b.title != title);
        }
        self.retarget_source_watch(cx); // path may have been replaced (atomic save)
        cx.notify();
    }
}
```

## Task 12: End-to-end integration test + full local gate

**Files:**
- Create: `crates/dat0-app/tests/live_data_recovery.rs`

- [ ] **Step 1: Write the e2e test** — re-import round-trip preserves structural transforms, drops rowid edits (headless; no GUI clicks).

```rust
// Builds a real DuckDBEngine over a temp scratch, imports a CSV, applies a
// filter + a cell edit, rewrites the CSV, re-imports, and asserts the filter
// survives (compiles) while the edit is dropped by split_replayable.
use dat0_engine::{DuckDBEngine, RegisterOpts, QueryEngine as _};
use dat0_engine::transform::{split_replayable, Transformation, /* CellEdit, ... */};
use tempfile::tempdir;

#[tokio::test]
async fn reimport_preserves_structural_drops_rowid() {
    let dir = tempdir().unwrap();
    let scratch = dir.path().join("scratch.duckdb");
    let engine = DuckDBEngine::new(&scratch, 256 * 1024 * 1024).unwrap();
    engine.init().await.unwrap();

    let csv = dir.path().join("sales.csv");
    std::fs::write(&csv, "id,qty\n1,5\n2,10\n").unwrap();
    let info = engine.register_file_as_table(&csv, RegisterOpts::default()).await.unwrap();
    assert!(info.row_count_estimate.unwrap_or(0) >= 2 || info.columns.len() == 2);

    // Simulate a stack: filter (structural) + an edit (rowid-keyed).
    let filter = Transformation::Filter {
        column: "qty".into(),
        op: dat0_engine::transform::FilterOp::Gt,
        value: dat0_engine::transform::FilterValue::Number(4.0),
    };
    // Construct a real CellEdit per transform.rs; placeholder shown:
    let edit = Transformation::Edit { cells: vec![/* CellEdit{ id:1, column:"qty".into(), value:.. } */] };
    let stack = vec![filter.clone(), edit];
    let split = split_replayable(&stack);
    assert_eq!(split.replayable.len(), 1);
    assert_eq!(split.dropped_edits, 1);

    // External change → re-import (same table name, refreshed rows).
    std::fs::write(&csv, "id,qty\n1,5\n2,10\n3,99\n").unwrap();
    let _ = engine.register_file_as_table(&csv, RegisterOpts::default()).await.unwrap();

    // The structural filter still compiles against the refreshed base.
    let sql = dat0_engine::compile_view_sql(&info.name, &split.replayable).unwrap();
    let page = engine.execute_paged(&sql, 0, 100).await.unwrap();
    // qty > 4 over {5,10,99} → 3 rows after the re-import added id=3.
    assert_eq!(page.total_rows, 3);

    engine.close().await.unwrap();
}
```

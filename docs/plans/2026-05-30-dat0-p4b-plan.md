# dat0 P4b — Edit + Selection + Clipboard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Match the P3a/P3b/P4a cadence: full two-stage review on T0 (PD-016 wiring + probes — the integration seam), T1 (typed enum + serde), T2 (render overlay — engine SQL surface), T3 (import surrogate + migration), T6 (cell editor — gpui-component mount), T7 (clipboard codec + paste), T13 (session v2→v3 + E2E); combined-verify on the mechanical tasks (T4, T5, T8, T9, T10, T11, T12, T14). Plan defects go to `docs/deferrals.md` as new `PD-NNN` entries — do not fix in place unless they block the task.

**Goal:** Land the P4b slice of spec §21.2 P4 — typed `Edit` + `RowDelete` transforms with a `RowKey` surrogate, an SQL overlay render (`* REPLACE` + `WHERE NOT IN`), keyboard-operable cell selection, type-aware inline cell editing, RFC-style TSV clipboard (cut/copy/paste round-tripping Excel + Google Sheets), fill-down + bulk ops, a selection-aware context menu, and the PD-016 UI-click wirings P4a deferred.

**Spec:** `docs/plans/2026-05-30-dat0-p4b-design.md` (committed 2026-05-30, `6f7de2a`). Read it before T0. The six locked decisions in §1 are binding.

**Architecture:** `Edit { cells: Vec<CellEdit> }` and `RowDelete { rows: Vec<RowKey> }` join the P4a `Transformation` enum and ride the same per-tab `ViewModel` stack + undo/redo + `ViewChange` → `spawn_view_change` → `apply_view_change` round-trip. Edits/deletes render as a base-level overlay subquery (`SELECT * REPLACE(<CASE per edited col>) … WHERE __dat0_rowid NOT IN(…)`) wrapped by the existing filter/sort clauses, so filters and sorts see edited values; when the active stack has no Edit/RowDelete, `compile_view_sql` emits P4a-identical flat SQL (zero golden/perf regression). Row identity is a synthetic monotonic `__dat0_rowid` surrogate injected at import, modeled as an extensible `RowKey` enum (`Surrogate(i64)` now; P7 adds `Pk` with no wire break). Selection is ephemeral keyboard-operable grid state, never persisted. session.json bumps v2 → v3 (additive variants, identity migration).

**Tech Stack:** Rust 2024, GPUI `=0.2.2`, gpui-component v0.5.1 (pinned commit `0f0ab35…`), `duckdb-rs =1.4.4` (features `bundled,json,parquet`), `serde`/`serde_json` (workspace), `tokio`. No new top-level deps expected (clipboard via GPUI; TSV codec hand-rolled). macOS + Linux v1.

## Phase context (read before T0)

- **P4b is the middle of the three-way split.** P4c (column reorder/rename/delete, PipelineBar, export-to-file dialog) follows. Anything not in the design §18 exit-criteria list is **not** a P4b exit — flag scope creep, don't absorb it. Specifically: **no PipelineBar, no column ops, no export dialog** in P4b.
- **PD-016 is T0 and gate-blocking.** P4a retro §"PD-016 decision" is an explicit, binding hand-off. T0 closes the funnel-click → popover, popover-`Outcome::Apply` → `spawn_view_change`, and sort-zone-click → `vm.set_sort` wirings, plus a click-path integration test. **Do not begin T4+ feature work until T0 lands** — the click seam is shared infrastructure for every later UI task.
- **The overlay render is internal to `compile_view_sql`.** Decision 3: edits side-table is deferred and adds no serialized-format change. Do not introduce any new mutable DB object for edits in P4b.
- **`MainThreadDispatcher` is the rebind path.** Every engine round-trip leading to a UI mutation posts via `crate::view::spawn_view_change(...)` (P4a T13) — never call `cx.update` from a tokio task directly. `dispatch_undo`/`dispatch_redo` in `crates/dat0-app/src/actions/view_actions.rs` are the canonical reference; new dispatch bodies copy their shape exactly.
- **gpui-component `Input`/`Select` mount needs a real `&mut Window`.** P4a T10b proved headless mount is infeasible (`InputState::new` requires `&mut Window`; T0 spike §3). The inline cell editor (T6) reuses the T10b mount pattern from `crates/dat0-app/src/view/filter_popover_entity.rs`. Subscriptions must be **stored** or callbacks fire silently (P4a T10b post-review finding).
- **`__dat0_rowid` is the row-identity invariant.** Decision 1. The name is fixed; a colliding source column is renamed to `__dat0_rowid__src` at import (not our key). The render path (`compile_view_sql`) references `__dat0_rowid` literally and needs no schema parameter.
- **Banner shape (P3b T2).** New banners (paste-reject) use `Banner::error/with_primary/with_secondary` — do not re-introduce the flat-message shape.
- **session.json forward-migration is one-shot + write-back** (P4a T8 pattern). v2 → v3 is identity; `migrate.rs` gains the v3 arm + an unknown-`kind` guard so a v3-written stack opened by an older binary shows the forward-incompat banner, not a hard serde error.

```rust
/// Sort-zone click (T0 / PD-016). Reads the current sort, cycles the clicked
/// column (plain or shift-extend), writes it back via `ViewModel::set_sort`,
/// and drives the engine round-trip exactly like `dispatch_undo`.
pub fn on_sort_zone_click(&mut self, col_ix: usize, shift: bool, cx: &mut Context<Self>) {
    let Some(column) = self.column_name(col_ix) else { return };
    let Some(vm) = self.view_model.as_mut() else { return };
    let active = vm.current_sort_as_active();
    let active = if shift { active.shift_click(&column) } else { active.click(&column) };
    let change = vm.set_sort(active.keys().to_vec());
    let engine = self.engine();
    let base_table = vm.base_table().to_string();
    let ws_weak = cx.entity().downgrade();
    crate::view::spawn_view_change(
        engine, base_table, change,
        std::sync::Arc::new(move |new_ds, app_cx| {
            if let Some(h) = ws_weak.upgrade() { h.update(app_cx, |ws, cx| ws.apply_view_change(new_ds, cx)); }
        }),
    );
}
```

```rust
/// Funnel-zone click (T0 / PD-016). Mounts the filter popover for `col_ix`,
/// pre-populated from any active filter on that column, and routes its
/// `Outcome` back into the ViewModel + engine round-trip.
pub fn on_funnel_click(&mut self, col_ix: usize, window: &mut Window, cx: &mut Context<Self>) {
    let Some(column) = self.column_name(col_ix) else { return };
    let pre = self.view_model.as_ref().and_then(|vm| vm.find_filter_for(&column).cloned());
    // Mount per the P4a T10b pattern (real &mut Window required).
    let popover = crate::view::FilterPopoverEntity::mount(&column, pre, window, cx);
    let ws_weak = cx.entity().downgrade();
    // STORE the subscription — callbacks fire silently otherwise (P4a T10b post-review).
    let sub = cx.subscribe(&popover, move |ws: &mut Self, _pop, ev, cx| {
        ws.route_filter_outcome(ev.outcome.clone(), cx); // ev wraps Outcome
    });
    self.popover_sub = Some(sub);
    self.active_popover = Some(popover);
    cx.notify();
}

fn route_filter_outcome(&mut self, outcome: crate::view::filter_popover_entity::Outcome, cx: &mut Context<Self>) {
    use crate::view::filter_popover_entity::Outcome;
    let Some(vm) = self.view_model.as_mut() else { return };
    let change = match outcome {
        Outcome::Apply(t) => Some(vm.apply(t)),
        Outcome::Clear { pre_populated: true } => Some(vm.clear()), // P4b: remove-filter refinement may narrow this; clear is the safe superset for v1
        Outcome::Clear { pre_populated: false } | Outcome::Cancel => None,
    };
    self.active_popover = None;
    self.popover_sub = None;
    let Some(change) = change else { cx.notify(); return };
    let engine = self.engine();
    let base_table = vm.base_table().to_string();
    let ws_weak = cx.entity().downgrade();
    crate::view::spawn_view_change(engine, base_table, change,
        std::sync::Arc::new(move |new_ds, app_cx| {
            if let Some(h) = ws_weak.upgrade() { h.update(app_cx, |ws, cx| ws.apply_view_change(new_ds, cx)); }
        }));
}
```

```rust
pub fn compile_view_sql(base: &str, ops: &[Transformation]) -> Result<String, RenderError> {
    let mut where_clauses: Vec<String> = Vec::new();
    let mut sort: Option<&[SortKey]> = None;
    // column -> ordered (key, literal) pairs; later entries override earlier per key (last-write-wins).
    let mut edits: std::collections::BTreeMap<String, Vec<(i64, String)>> = Default::default();
    let mut deleted: Vec<i64> = Vec::new();

    for op in ops {
        match op {
            Transformation::Filter { column, op, value } => where_clauses.push(render_filter(column, op, value)?),
            Transformation::Sort { keys } => sort = Some(keys.as_slice()),
            Transformation::Edit { cells } => {
                if cells.is_empty() { return Err(RenderError::EmptyEdit); }
                for c in cells {
                    let RowKey::Surrogate(k) = c.row;
                    let lit = render_scalar(&c.value);
                    let col = edits.entry(c.column.clone()).or_default();
                    col.retain(|(ek, _)| *ek != k); // last write wins
                    col.push((k, lit));
                }
            }
            Transformation::RowDelete { rows } => {
                if rows.is_empty() { return Err(RenderError::EmptyRowDelete); }
                for r in rows { let RowKey::Surrogate(k) = *r; deleted.push(k); }
            }
        }
    }

    let has_overlay = !edits.is_empty() || !deleted.is_empty();
    let mut inner = if has_overlay {
        let mut s = String::from("SELECT * REPLACE (");
        let cols: Vec<String> = edits.iter().map(|(col, pairs)| {
            let qcol = quote_ident(col);
            let mut case = format!("CASE");
            for (k, lit) in pairs { case.push_str(&format!(" WHEN __dat0_rowid = {} THEN {}", k, lit)); }
            case.push_str(&format!(" ELSE {} END AS {}", qcol, qcol));
            case
        }).collect();
        s.push_str(&cols.join(", "));
        s.push_str(&format!(") FROM {}", base));
        if !deleted.is_empty() {
            let list = deleted.iter().map(|k| k.to_string()).collect::<Vec<_>>().join(", ");
            s.push_str(&format!(" WHERE __dat0_rowid NOT IN ({})", list));
        }
        format!("({})", s)
    } else {
        base.to_string()
    };

    // Outer filter/sort. When no overlay, this reproduces the P4a flat SQL exactly.
    let mut sql = format!("SELECT * FROM {}", inner);
    if !where_clauses.is_empty() { sql.push_str(" WHERE "); sql.push_str(&where_clauses.join(" AND ")); }
    if let Some(keys) = sort { if !keys.is_empty() { sql.push_str(" ORDER BY "); sql.push_str(&render_sort(keys)); } }
    // Strip the redundant `FROM (base)`→`FROM base` wrapper when no overlay so output is byte-identical to P4a.
    if !has_overlay { sql = sql.replacen(&format!("SELECT * FROM {}", inner), &format!("SELECT * FROM {}", base), 1); }
    let _ = &mut inner;
    Ok(sql)
}
```

```rust
pub const ROWID_COL: &str = "__dat0_rowid";

// inside impl QueryEngine for DuckDBEngine:
async fn ensure_rowid(&self, table: &str) -> Result<(), EngineError> {
    let t = crate::catalog::quote_ident(table);
    self.with_conn(move |conn| {
        let has = column_exists(conn, &t, ROWID_COL)?;
        if has {
            // Distinguish our injected key from a colliding source column: ours is BIGINT NOT NULL,
            // gap-free 0..n-1. Simplest robust rule for v1: if present and not our marker, rename source col.
            // Use a sentinel COMMENT to mark ours; if absent, treat as collision.
            if !is_marked_rowid(conn, &t)? {
                conn.execute_batch(&format!(
                    "ALTER TABLE {t} RENAME COLUMN {ROWID_COL} TO {ROWID_COL}__src;"))?;
            } else { return Ok(()); }
        }
        // Inject deterministic surrogate in physical scan order.
        conn.execute_batch(&format!(
            "ALTER TABLE {t} ADD COLUMN {ROWID_COL} BIGINT;\n\
             UPDATE {t} SET {ROWID_COL} = seq.rn FROM (\n\
               SELECT rowid AS rid, (row_number() OVER (ORDER BY rowid)) - 1 AS rn FROM {t}\n\
             ) seq WHERE {t}.rowid = seq.rid;\n\
             COMMENT ON COLUMN {t}.{ROWID_COL} IS 'dat0:surrogate';"))?;
        Ok(())
    }).await
}
```

```rust
//! Ephemeral grid selection state (design §7). Pure-logic, never persisted.
//! Screen-space coordinates over the active (filtered/sorted) view; resolved
//! to RowKey at copy/edit time via the hidden key column (see grid::data_source).

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct CellCoord { pub row: usize, pub col: usize }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct CellRange { pub r0: usize, pub c0: usize, pub r1: usize, pub c1: usize } // inclusive

impl CellRange {
    fn contains(&self, r: usize, c: usize) -> bool {
        r >= self.r0.min(self.r1) && r <= self.r0.max(self.r1)
            && c >= self.c0.min(self.c1) && c <= self.c0.max(self.c1)
    }
}

#[derive(Debug, Clone)]
pub struct SelectionModel {
    rows: usize, cols: usize,
    ranges: Vec<CellRange>,
    anchor: CellCoord,
    active: CellCoord,
}

impl SelectionModel {
    pub fn new(rows: usize, cols: usize) -> Self {
        let z = CellCoord { row: 0, col: 0 };
        Self { rows, cols, ranges: Vec::new(), anchor: z, active: z }
    }
    pub fn active(&self) -> CellCoord { self.active }
    pub fn clear(&mut self) { self.ranges.clear(); }

    pub fn click(&mut self, c: CellCoord) {
        self.ranges.clear();
        self.anchor = c; self.active = c;
        self.ranges.push(CellRange { r0: c.row, c0: c.col, r1: c.row, c1: c.col });
    }
    pub fn add_click(&mut self, c: CellCoord) { // Cmd/Ctrl+click — new discontiguous range
        self.anchor = c; self.active = c;
        self.ranges.push(CellRange { r0: c.row, c0: c.col, r1: c.row, c1: c.col });
    }
    pub fn extend_to(&mut self, c: CellCoord) { // Shift — replace last range from anchor
        self.active = c;
        if let Some(last) = self.ranges.last_mut() {
            *last = CellRange { r0: self.anchor.row, c0: self.anchor.col, r1: c.row, c1: c.col };
        } else {
            self.ranges.push(CellRange { r0: self.anchor.row, c0: self.anchor.col, r1: c.row, c1: c.col });
        }
    }
    pub fn select_row(&mut self, r: usize) {
        self.click(CellCoord { row: r, col: 0 });
        if let Some(last) = self.ranges.last_mut() { last.c1 = self.cols.saturating_sub(1); }
    }
    pub fn select_column(&mut self, c: usize) {
        self.click(CellCoord { row: 0, col: c });
        if let Some(last) = self.ranges.last_mut() { last.r1 = self.rows.saturating_sub(1); }
    }
    pub fn select_all(&mut self) {
        self.ranges.clear();
        self.ranges.push(CellRange { r0: 0, c0: 0, r1: self.rows.saturating_sub(1), c1: self.cols.saturating_sub(1) });
    }
    pub fn contains(&self, r: usize, c: usize) -> bool { self.ranges.iter().any(|x| x.contains(r, c)) }

    /// Deduped (row, col) pairs across all ranges, row-major.
    pub fn resolved_cells(&self) -> impl Iterator<Item = (usize, usize)> + '_ {
        let mut set = std::collections::BTreeSet::new();
        for rg in &self.ranges {
            for r in rg.r0.min(rg.r1)..=rg.r0.max(rg.r1) {
                for c in rg.c0.min(rg.c1)..=rg.c0.max(rg.c1) { set.insert((r, c)); }
            }
        }
        set.into_iter()
    }
    // Keyboard movers (T11 wires keys → these):
    pub fn move_active(&mut self, dr: isize, dc: isize) {
        let r = (self.active.row as isize + dr).clamp(0, self.rows as isize - 1) as usize;
        let c = (self.active.col as isize + dc).clamp(0, self.cols as isize - 1) as usize;
        self.click(CellCoord { row: r, col: c });
    }
    pub fn extend_active(&mut self, dr: isize, dc: isize) {
        let r = (self.active.row as isize + dr).clamp(0, self.rows as isize - 1) as usize;
        let c = (self.active.col as isize + dc).clamp(0, self.cols as isize - 1) as usize;
        self.extend_to(CellCoord { row: r, col: c });
    }
}
```

```rust
//! TSV clipboard codec (design §10). Dialect targets the de-facto Excel/Sheets
//! clipboard format: tab columns, CRLF rows, CSV-style quoting for cells
//! containing tab/CR/LF/double-quote.

pub fn tsv_serialize(grid: &[Vec<String>]) -> String {
    grid.iter().map(|row| row.iter().map(|c| quote(c)).collect::<Vec<_>>().join("\t"))
        .collect::<Vec<_>>().join("\r\n")
}

fn quote(cell: &str) -> String {
    if cell.contains('\t') || cell.contains('\n') || cell.contains('\r') || cell.contains('"') {
        format!("\"{}\"", cell.replace('"', "\"\""))
    } else { cell.to_string() }
}

pub fn tsv_parse(tsv: &str) -> Vec<Vec<String>> {
    let mut rows = Vec::new();
    let mut row = Vec::new();
    let mut cell = String::new();
    let mut chars = tsv.chars().peekable();
    let mut in_quotes = false;
    while let Some(ch) = chars.next() {
        match ch {
            '"' if in_quotes => {
                if chars.peek() == Some(&'"') { chars.next(); cell.push('"'); } else { in_quotes = false; }
            }
            '"' if cell.is_empty() && !in_quotes => in_quotes = true,
            '\t' if !in_quotes => { row.push(std::mem::take(&mut cell)); }
            '\r' if !in_quotes => { /* swallow; \n closes the row */ }
            '\n' if !in_quotes => { row.push(std::mem::take(&mut cell)); rows.push(std::mem::take(&mut row)); }
            other => cell.push(other),
        }
    }
    if !cell.is_empty() || !row.is_empty() { row.push(cell); rows.push(row); }
    rows
}

pub enum CoerceResult { Ok(dat0_engine::Scalar), Skip }

/// Coerce a pasted string into the target Arrow type name. Invalid → Skip.
pub fn coerce_cell(s: &str, arrow_type: &str) -> CoerceResult {
    use dat0_engine::Scalar;
    let t = arrow_type;
    if t.starts_with("Int") || t.starts_with("UInt") {
        s.trim().parse::<i64>().map(|i| CoerceResult::Ok(Scalar::Int(i))).unwrap_or(CoerceResult::Skip)
    } else if t.starts_with("Float") || t.starts_with("Decimal") {
        s.trim().parse::<f64>().map(|f| CoerceResult::Ok(Scalar::Float(f))).unwrap_or(CoerceResult::Skip)
    } else if t == "Boolean" {
        match s.trim().to_ascii_lowercase().as_str() {
            "true" | "1" => CoerceResult::Ok(Scalar::Bool(true)),
            "false" | "0" => CoerceResult::Ok(Scalar::Bool(false)),
            _ => CoerceResult::Skip,
        }
    } else if t.starts_with("Date") {
        match Scalar::validate_date(s.trim()) { Ok(v) => CoerceResult::Ok(Scalar::Date(v.to_string())), Err(_) => CoerceResult::Skip }
    } else if t.starts_with("Timestamp") {
        match Scalar::validate_timestamp(s.trim()) { Ok(v) => CoerceResult::Ok(Scalar::Timestamp(v.to_string())), Err(_) => CoerceResult::Skip }
    } else {
        CoerceResult::Ok(Scalar::Str(s.to_string()))
    }
}
```

## Catalog dock — toggle + tree (T6–T7)
- [ ] **View → Toggle Catalog** opens the left Catalog dock; invoking it again **closes** it (toggle).
- [ ] The tree shows three sections with live counts: **Sources (n)**, **Tables (n)**, **Derived (n)**.
- [ ] An imported file (CSV/Parquet) appears under **Sources**; a `CREATE TABLE AS` / transform-derived table appears under **Derived**; a plain in-session base table appears under **Tables**.
- [ ] With MotherDuck connected (or a SQLite file attached via the Connections panel), the attached database's **tables appear under Sources** (per-table enumeration — D-012 attach remainder).
- [ ] Typing in the search box filters nodes by name (token-AND, case-insensitive) — e.g. `dai rev` keeps `daily_revenue`.

## Catalog → open + inspect (T7 + T9)
- [ ] **Click a catalog node** → that table loads into the main grid.
- [ ] **View → Toggle Inspector** opens the right Inspector dock; clicking a catalog node (or opening a table) populates it within **~2 s** for a large table.
- [ ] The Inspector overview shows the table name, **row count**, and **column count**.

## Inspector — column cards + charts (T9 + T10)
- [ ] A **numeric** column card shows `min · max · μ · med · σ` and (for higher-cardinality numerics) a **histogram** (16 bars).
- [ ] A **low-cardinality** column (categorical) shows **top-N horizontal bars** of its most frequent values.
- [ ] Each card shows the **approximate distinct** count (labelled *approx*) and the **null %**.
- [ ] *(Cosmetic, known)* The internal `__dat0_rowid` surrogate column may appear as a card — note if so; it is harmless and a candidate to hide in a follow-up.

## Inspector — whole-table ⇄ current-view toggle (T9)
- [ ] Apply a **filter** in the grid (so the view has fewer rows than the base table).
- [ ] In the Inspector, the **Whole table ⇄ Current view** toggle button flips mode; switching to **Current view** re-profiles and the **stats change** to reflect the filtered rows (row count drops, distributions shift). Switching back to **Whole table** restores the full-table stats.

## Inspector — dependents (live) (T11)
- [ ] Select a base table, then **apply a transform** to it / save a transform-derived child → the child appears in the Inspector's **Dependents (live)** section for the parent.
- [ ] Dropping/recreating tables updates the Dependents list without needing a reselect.

## Inspector — refresh on mutation (T12)
- [ ] With a table inspected, **edit a cell** (or paste/cut/delete/fill) → the Inspector profile **refreshes** to reflect the change (stats/charts update; in Current-view mode the edit overlay is included).
- [ ] **Known gap (PD-022):** **undo/redo** of a mutation (and SQL-console grid re-bind) does **not** yet refresh the Inspector — it updates on the next forward mutation, reselect, or mode toggle. Confirm this is the only stale path.

## Banner host (T1 / PD-021)
- [ ] Trigger an **export** (File → Export) and let it complete → an inline **banner strip** appears at the top of the window confirming success (and a red banner on a forced failure, e.g. export to an unwritable path).
- [ ] A **paste-reject** (paste incompatible values) surfaces its banner too (previously invisible).

## Persistence — session v8 (T13)
- [ ] Open both docks, then **quit and relaunch** the app reopening the same workspace → the **Catalog and Inspector dock visibility is restored** to how you left it.
- [ ] *(Forward-looking)* `catalog_expanded` / `catalog_selection` are persisted in the v8 schema but the catalog currently renders flat (no expand/collapse UI), so there is nothing to restore there yet — confirm no error on load of a fresh v8 file.

## Migration safety (T13)
- [ ] Open a workspace whose `session.json` predates P6a (v1–v7) → it loads cleanly, docks default to hidden, and on next write the file is stamped **schema v8** (no data loss; tabs/queries/attachments preserved).
